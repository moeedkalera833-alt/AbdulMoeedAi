عبدالمعید AI — ابتدائی Android پروجیکٹ

اہم:
- یہ Android Studio / AndroidIDE کے لیے سورس پروجیکٹ ہے، ابھی APK فائل نہیں۔
- پہلے ورژن میں مائیک بٹن دبانے پر اردو وائس ریکگنیشن کھلتی ہے۔
- معاون WhatsApp، YouTube، Chrome، Settings، Wi‑Fi، Bluetooth اور Dialer کھول سکتا ہے۔
- کال خود بخود نہیں ملائی جاتی؛ فون ایپ کھلتی ہے تاکہ آپ خود نمبر منتخب/تصدیق کریں۔
- Urdu Text-to-Speech کی دستیابی فون کے نصب شدہ زبان پیک پر منحصر ہے۔
- Accessibility service صرف ابتدائی بنیاد ہے؛ اسے فعال کرنا لازمی نہیں اور ابھی خودکار کلک/اسکرین کنٹرول نافذ نہیں۔

موبائل پر APK بنانے کا عمومی طریقہ:
1) AndroidIDE جیسی Android پر IDE ایپ انسٹال کریں۔
2) اس ZIP کو Extract کریں۔
3) AndroidIDE میں AbdulMoeedAI فولڈر بطور Gradle project کھولیں۔
4) Gradle sync مکمل ہونے دیں۔
5) Build > Assemble Debug چلائیں۔
6) بننے والی app-debug.apk انسٹال کریں۔
اگر Gradle یا SDK ورژن کا مسئلہ آئے تو error کا اسکرین شاٹ بھیجیں؛ اس کے مطابق پروجیکٹ درست کریں۔

اجازتیں:
- Microphone: صرف آواز سننے کے لیے۔
- Accessibility: فی الحال اختیاری اور ابتدائی سروس۔
- ایپ خودکار طور پر پیغامات یا کال نہیں بھیجتی۔
